# DeskFolders

Бесплатные папки на рабочем столе Windows в стиле телефона (аналог DeskRipple).
Иконка-папка лежит прямо на рабочем столе за окнами, как обычный значок. Клик —
папка раскрывается полупрозрачной сеткой ярлыков с анимацией. Клик по ярлыку — запуск.

## Запуск

Готовое приложение — один файл, **Python и .NET ставить не нужно**:

```
DeskFolders\publish\DeskFolders.exe
```

Просто запусти его. В трее (возле часов) появится значок — правый клик по нему даёт меню.
Чтобы запускать при старте Windows: правый клик по значку в трее →
**«Запускать при старте Windows»**.

## Как пользоваться

- **Показать все папки поверх окон** — горячая клавиша **Ctrl+Shift+D**: все папки
  всплывают непрозрачными плитками поверх любых окон, фон слегка затемняется. Клик по
  папке открывает её, клик мимо (или повторное нажатие Ctrl+Shift+D) — всё скрывается.
  Клавишу можно сменить в `config.json` (`HotkeyModifiers`: 1=Alt, 2=Ctrl, 4=Shift, 8=Win,
  складываются; `HotkeyVk` — код клавиши).
- **Открыть папку** — левый клик по иконке-папке на столе.
- **Запустить программу** — клик по ярлыку в раскрытой папке.
- **Переместить папку** — перетащи иконку-папку мышью в любое место стола (позиция запоминается).
- **Добавить ярлыки перетаскиванием** — перетащи `.exe`, ярлык `.lnk`, файл или папку
  с рабочего стола (или из Проводника) прямо на иконку-папку. Она подсветится синим —
  отпускай.
- **Сортировка ярлыков** — в раскрытой папке перетащи иконку ярлыка на место
  другого, порядок сохранится.
- **Удалить ярлык из папки** — правый клик по ярлыку в раскрытой папке →
  «Удалить из папки» (там же «Запустить» и «Открыть расположение файла»).
- **Открытие по наведению или по клику** — переключается в меню трея →
  «Открывать по наведению мыши».
- **Правый клик по папке** — «Открыть», «Настроить папку…», «Убрать с рабочего стола».
- **Менеджер папок** (двойной клик по значку в трее или пункт меню) — создавать/удалять
  папки, переименовывать, добавлять ярлыки через диалог, менять порядок.
- **Добавить установленные приложения** — в менеджере кнопка «＋ Установленное…»
  показывает список всех установленных программ (из меню «Пуск») с поиском и галочками;
  отметь нужные и нажми «Добавить выбранные».

Приложение защищено от двойного запуска: повторный запуск `.exe` не создаёт второй
значок, а открывает менеджер уже работающего экземпляра.

## Где хранятся настройки

`%APPDATA%\DeskFolders\config.json` — список папок, их позиции и ярлыки.
`%APPDATA%\DeskFolders\shortcuts\` — копии ярлыков: при добавлении `.lnk`/`.url`
копируется сам файл, а при добавлении программы (`.exe`/`.bat`/`.cmd`) создаётся ярлык
на неё. Поэтому исходный ярлык можно удалять с рабочего стола — из папки всё работает.
Удаление каталога `%APPDATA%\DeskFolders` возвращает всё к начальному состоянию.

## Выход

Правый клик по значку в трее → **«Выход»**.

## Для разработки

Собрано на C# / WPF (.NET 6). Пересборка самостоятельного exe:

```
cd DeskFolders
dotnet publish -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
  -p:EnableCompressionInSingleFile=true -o publish
```

Отладочная сборка (нужен установленный .NET 6 Desktop Runtime): `dotnet build -c Release`.
